# 截图目录

此目录用于存放应用截图，用于 README.md 展示。

## 命名规范

- `connection_list.png` - 连接列表页面
- `add_connection.png` - 添加连接页面
- `file_browser.png` - 文件浏览器页面
- `transfer_queue.png` - 传输队列页面
- `image_preview.png` - 图片预览页面
- `video_player.png` - 视频播放页面
- `settings.png` - 设置页面

## 截图要求

- **设备** - 使用 Pixel 或其他原生 Android 设备
- **分辨率** - 1080x1920 或更高
- **主题** - 浅色主题
- **语言** - 中文
- **格式** - PNG（无损压缩）
- **大小** - 每张不超过 500KB

## 如何截图

1. 运行应用
2. 导航到要截图的页面
3. 使用 Android Studio 的截图功能（Device Explorer > Screen Capture）
4. 或使用设备的截图功能（电源键 + 音量减）
5. 将截图保存到此目录
